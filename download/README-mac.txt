FLIX VISION — MAC SETUP
========================

STEP 1 — Install Node.js (free, one-time only)
  Download from: https://nodejs.org
  Click the big LTS button, run the installer, click through everything.
  You only ever need to do this once.

STEP 2 — Extract this zip
  Double-click the zip to extract it.
  Move the folder anywhere — Downloads or Desktop is fine.

STEP 3 — Run Flix Vision
  Open the extracted folder and double-click:

      start-mac.command

  Your browser launches automatically with Flix Vision ready to use.

  If Mac says it can't be opened:
  → Right-click start-mac.command → click Open → click Open anyway
  OR go to: System Settings → Privacy & Security → click Allow Anyway

EVERY TIME YOU WANT TO USE IT:
  Just double-click start-mac.command again.

TO STOP:
  Close the terminal window that opened, or press Ctrl+C inside it.

PROBLEMS?
  "node: command not found"
  → Node.js is not installed. Go to nodejs.org and install it.

  Browser doesn't open automatically
  → Manually open your browser and go to: http://127.0.0.1:8080
