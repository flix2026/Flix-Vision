FLIX VISION — WINDOWS SETUP
============================

STEP 1 — Install Node.js (free, one-time only)
  Download from: https://nodejs.org
  Click the big LTS button, run the installer, click Next through everything.
  You only ever need to do this once.

STEP 2 — Extract this zip
  Right-click the zip → Extract All
  Put the folder anywhere — Desktop is fine.

STEP 3 — Run Flix Vision
  Open the extracted folder and double-click:

      run.bat

  A black window opens briefly, then your browser launches automatically
  with Flix Vision ready to use. That's it.

EVERY TIME YOU WANT TO USE IT:
  Just double-click run.bat again.

TO STOP:
  Close the black terminal window, or press Ctrl+C inside it.

PROBLEMS?
  "node is not recognized"
  → Node.js is not installed. Go to nodejs.org and install it.

  Browser doesn't open automatically
  → Manually open your browser and go to: http://127.0.0.1:8080

  Port already in use
  → Restart your PC, then try again.
